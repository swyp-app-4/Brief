# Brife (뉴스 추천 앱)

> 사용자 취향 저격 뉴스, 앱 실행 없이 홈 화면에서 바로 확인하세요.  
> 바쁜 현대인을 위해 개인화된 뉴스 큐레이션을 제공하는 안드로이드 앱 서비스입니다.

## 프로젝트 소개 (About)

본 프로젝트는 정보 과잉의 시대에서 사용자가 원하는 정보만을 쉽고 빠르게 접할 수 있도록 돕기 위해 기획되었습니다.  
사용자의 관심사를 분석하여 맞춤형 뉴스를 제공하며, 특히 위젯 서비스를 통해 접근성을 극대화했습니다.

### 핵심 기능
- 개인 맞춤형 추천: 관심 키워드 기반 뉴스 큐레이션 알고리즘 적용
- 뉴스 저장(아카이빙): 나중에 다시 보고 싶은 뉴스를 개인 보관함에 저장 및 관리
- 실시간 위젯: 앱을 열지 않아도 홈 화면에서 최신 헤드라인 확인 가능
- 간편 소셜 로그인: Naver, Kakao, Google 계정을 통한 빠른 시작 및 개인화 설정 유지

## 타겟 사용자 (Target Audience)

- Efficient Info-Seekers: 핵심 트렌드를 짧은 시간 안에 파악하고 싶은 직장인 및 학생  
- Customized Reader: 본인이 설정한 특정 분야(IT, 경제, 스포츠 등)의 소식만 집중해서 보고 싶은 분  
- Widget Enthusiast: 앱 진입 단계를 줄이고 홈 화면을 생산적으로 활용하고 싶은 사용자
